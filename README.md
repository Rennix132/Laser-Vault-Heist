# Laser Vault Heist

Computer Graphics Fundamentals, Final Project. C++17 / OpenGL 3.3 core profile.

## Build (Windows, MSYS2 UCRT64)

    cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
    cmake --build build
    ./build/LaserVaultHeist.exe

Requires: CMake, Ninja, GCC (MSYS2 UCRT64 toolchain), Git, internet on first
configure (GLFW and GLM are downloaded by CMake). GLAD and stb_image are in `external/`.
